# Redes — Módulo 3: Conectividade Móvel

## O celular como múltiplos dispositivos

O celular funciona como vários aparelhos ao mesmo tempo:
telefone, computador, GPS, cartão, controle de acessórios
e rádio. Cada função usa um tipo diferente de rede.

## Primeira rede — Rede celular (4G/5G)

Usa a infraestrutura que já vimos:

Celular → Antena → ISP → Internet


Depende do plano de dados contratado. Usada para:
- Navegar
- Assistir vídeos
- WhatsApp e Instagram
- Chamadas pela internet

## Segunda rede — Wi-Fi

Quando chegamos em casa, o celular troca automaticamente
para o Wi-Fi e para de usar o plano de dados.

Celular → Wi-Fi → Roteador → ISP → Internet


É basicamente a mesma internet — só muda o caminho até chegar nela.

**Diferença entre 4G e Wi-Fi:**
- 4G usa as antenas da operadora
- Wi-Fi usa o roteador de casa

## Terceira rede — GPS

O GPS não depende da internet para descobrir a localização —
usa satélite. A internet só entra quando vamos pesquisar
algo relacionado, como um restaurante próximo.

## Quarta rede — Bluetooth

Usado para conectar aparelhos próximos:
fone, controle, mouse, teclado, caixa de som, relógio.

Não usa internet nem Wi-Fi — funciona por conta própria.
Características: gasta pouca bateria e serve só para
curtas distâncias.

Para dois aparelhos se conectarem via Bluetooth é preciso
passar por um processo chamado **emparelhamento**.

**Modo detectável** é a opção que permite que outros
aparelhos consigam encontrar o seu via Bluetooth.

## Quinta rede — NFC (Comunicação de Campo Próximo)

É o que usamos como "cartão digital" no celular.
Precisa estar bem próximo do leitor para funcionar.

## Outros conceitos do módulo

**SSID** é o nome da rede Wi-Fi.

**Tethering** é compartilhar a internet de um dispositivo
com outro. Por exemplo: celular com dados 4G compartilhando
internet com um notebook que está sem conexão.
